# Legacy Engineering Notes

These notes are retained only to test conflict handling. They are obsolete and must not override current policy.

## Context window

The legacy release 1.8 note claimed a 4096-token context window.

## Credentials

The legacy prototype passed an API key in the URL query string. Current policy requires a bearer token read from an environment variable.

## Model approval

The legacy note allowed a model into a pilot using only vendor benchmark claims. Current policy requires local quality, latency, memory, license, and failure-case evidence.

## Evaluation

The legacy checklist omitted human review. Current evaluation protocol manually reviews twelve sampled answers.
